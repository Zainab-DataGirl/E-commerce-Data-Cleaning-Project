# E-Commerce Data Cleaning Project

## Overview
This project demonstrates data cleaning skills using a real-world Brazilian e-commerce dataset.

## Dataset
- **Source:** Kaggle - Olist Brazilian E-Commerce Public Dataset
- **Size:** 99,540 rows × 12 columns
- **Issues addressed:** Missing values, duplicates, inconsistent formatting, invalid entries

## Tools Used
- Microsoft Excel (data cleaning, filtering, formatting)

## Key Skills Demonstrated
- Data profiling and quality assessment
- Handling missing values
- Removing duplicates
- Text standardization
- Data validation

## Results
- Removed 173 problematic records (0.17% of data)
- Standardized all categorical variables
- Prepared dataset for business analysis
